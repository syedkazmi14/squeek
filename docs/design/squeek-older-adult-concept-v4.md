# Squeek: older-adult design refinement

Generated with the built-in image generation tool by editing the warm v3 concept. This is a visual proposal; it has not been implemented or tested with older adults.

## Design intent

Preserve warmth through a modest cursor character and cream/peach colors. Keep explanations in a stable, predictable panel. Use familiar typography, roomy labeled controls, and one prominent protective action. Reduce decorative character size and eliminate the oversized mascot and speech tail.

Accessibility targets for implementation: resizable text, measured text and control contrast, large pointer targets, keyboard access, visible focus, screen-reader labels, speech replay with text equivalent, reduced motion, and no timed dismissal. Exact pixel sizes and contrast have not been measured in the generated image.

W3C discusses age-related visual, motor, hearing, and cognitive needs in [Older Users and Web Accessibility](https://www.w3.org/WAI/older-users/). Its [Target Size (Enhanced)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html) guidance describes 44 by 44 CSS pixel targets at Level AAA and recommends considering larger targets. These are design references, not a compliance claim for this mockup.

Existing wording was preserved for this visual iteration. Before implementation, user-approved action labels must make clear what Cancel and Review actually do. Do not confuse dismissing a warning with cancelling a risky browser action. Warnings need uncertainty-aware wording appropriate to the assessment.

Usability check with representative older users: can they identify the warning, explain which action to take, and replay the explanation without assistance? Check keyboard operation and enlarged text in the implemented app. Age alone does not establish a user's abilities or visual preferences.

## Generation prompt

Use case: ui-mockup. Edit the provided Windows desktop screenshot to refine Squeek specifically for an older adult as the primary user. Keep warmth and original character personality, but build a mature, reassuring, very legible interface. Preserve the Windows desktop and recognizable email browser with its existing neutral placeholders. Show a high-fidelity full desktop concept screenshot, landscape.
Replace the giant cartoon speech blob with one stationary elegantly rounded warm-ivory panel at the right, with ordinary predictable rounded rectangular boundaries, excellent whitespace and a gentle shadow. Reduce the mascot to a small original butter-yellow rounded cursor-arrow character with two tiny subtle eyes, no hands, feet, pink cheeks, hats or exaggerated expressions. Put it beside the "Squeek" name as a modest 40px-equivalent emblem. A smaller matching character remains near the real pointer at the suspicious link; it is clearly distinct from the normal arrow, never covering the link. No larger decorative character perched on the panel. No long speech tail, motion rays, visual confetti or thick comic outlines.
Use quiet personality through warm butter/cream/soft peach colors and rounded forms. All text uses a familiar clean humanist sans serif resembling Segoe UI or Atkinson Hyperlegible, not bubble lettering. Very dark ink/plum text on ivory, medium weight rather than heavy cartoon bold. Main warning 30px-equivalent and body 24px-equivalent with roomy line spacing. Avoid oversized branding. Header small mascot and "Squeek", with plainly labeled "Mute" control sized at least 56px-equivalent tall.
Exact main warning: "Hey, this is a scam, don't click on it", set in sentence case with natural line breaks, no all capitals, no added prose. Below it one simple warm-peach evidence inset titled "Evidence", with large readable "[Scam signal]" and "[Message excerpt]". No additional nested cards, no percentage, no skeleton bars inside Squeek. Use only one modest amber cue near the warning; don't rely on color alone because the warning is also visible in text.
Actions: one prominent full-width deep-plum "Cancel" button with crisp white text, at least 68px-equivalent tall; one generously spaced full-width outlined "Replay" button with speaker icon and dark label; "Review" as a third clearly labeled secondary control with ample target size and visual breathing room. Prioritize the safe action visually, avoid equal competing brightly colored buttons. Keep all controls in one predictable vertical column; do not hide essential controls behind icons. No countdown or timed dismissal.
Keep browser to the left and panel fully within the desktop with a gap above the taskbar; narrow browser slightly if needed rather than cover its main message. This should feel like a thoughtful helpful adult companion: friendly and distinctive, yet quiet enough to read carefully. No corporate security dashboard, no toy-like character, no glass gradients. Only text allowed in Squeek is "Squeek", "Hey, this is a scam, don't click on it", "Evidence", "[Scam signal]", "[Message excerpt]", "Cancel", "Replay", "Review", "Mute". Preserve existing email text/placeholders, don't invent email prose, names, timestamps, locations, slogans or statuses. No watermark or annotations.
